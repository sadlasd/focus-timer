# Фокус

Небольшой учебный проект на React: таймер для учёбы и список задач. Можно выбрать одно дело, позаниматься 25 минут и сделать перерыв.

## Возможности

- Три режима: фокус на 25 минут, перерывы на 5 и 15 минут.
- Запуск, пауза, продолжение и сброс таймера.
- Добавление, завершение и удаление задач.
- Выбор текущей задачи и счётчик законченных сессий.
- Сохранение задач в браузере через localStorage.
- Адаптивная вёрстка для телефона и компьютера.

## Стек

React, JavaScript, обычный CSS и Vite. Без сервера, базы данных и UI-библиотек.

## Запуск

Нужен Node.js версии 22.12 или новее.

```sh
npm ci
npm run dev
```

Открой адрес, который появится в терминале.

```sh
npm test          # тесты расчёта времени
npm run build    # сборка в папку dist
npm run preview  # просмотр сборки
```

## Как устроен код

- `src/App.jsx` — главный экран, состояние задач и работа с localStorage.
- `src/TaskList.jsx` — форма добавления и список задач; получает данные и обработчики через props.
- `src/useTimer.js` — состояние и действия таймера в отдельном хуке.
- `src/timer.js` — длительность режимов и функции расчёта времени.
- `src/styles.css` — все стили, включая мобильную версию.
- `src/useWebMcp.js` — необязательная интеграция с Sites для добавления задач из чата. В браузерах без поддержки WebMCP не включается; основное приложение работает без неё.

Задачи хранятся в массиве. Для изменения используется `map`, для удаления — `filter`. Состояние обновляется через `useState`, а сохранение в браузер и запуск интервала — через `useEffect`.

Таймер хранит время окончания сессии. Каждое обновление сравнивает его с `Date.now()`, а не просто вычитает секунду. Это помогает учитывать задержки обновления фоновой вкладки. При паузе сохраняется оставшееся количество секунд. Интервал очищается при паузе, сбросе и смене режима.

## Ограничения

Задачи доступны только в том браузере, где были добавлены: синхронизации и аккаунтов нет. Таймер, выбранная задача и счётчик сессий сбрасываются после перезагрузки страницы. Переключение режима тоже сбрасывает таймер. Звукового уведомления нет; сообщение о завершении появляется на странице. Первые три задачи — примеры.

## Что можно доработать самостоятельно

- Настройку длительности сессии.
- Редактирование названия задачи.
- Звук после окончания таймера.
- Сохранение таймера между перезагрузками.

## Ручная проверка

1. Запусти таймер, поставь на паузу и продолжи: время должно сохраниться.
2. Переключи режим: таймер должен остановиться и показать новую длительность.
3. Добавь задачу, выбери её и отметь выполненной.
4. Перезагрузи страницу: задачи остаются, таймер начинается заново.
5. Уменьши ширину окна: карточки должны выстроиться в одну колонку.
